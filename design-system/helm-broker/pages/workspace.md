# Broker workspace overrides

This is an operations application, not a marketing landing page. Override the
generated master pattern's hero/CTA sections with a compact casework surface.

- Forest sidebar, off-white canvas, sage review states and restrained amber alerts.
- DM Sans for controls and data; Georgia for the editorial page heading.
- Light-only interface with sidebar/navigation, four live counts, case queue and review drawer.
- No agent-team page or decorative team strip. Audit trails open from each case row;
  there is no combined workspace audit page.
- Use existing Lucide icons. No decorative bitmap imagery is needed for casework.
- Human approval, uncertainty and demo boundaries must remain explicit.
- Native dialog focus management and Escape dismissal for the case workspace.
- At phone widths, case rows become stacked summaries; statuses stay visible.
- Avoid heavy blur/morphing from the generated liquid-glass suggestion: dense
  operational information needs stable surfaces. Honour reduced-motion preferences.
